Install

Chrome and Firefox need separate Manifest V3 packages. Build them once, then load the matching folder.

1. Build

  1. Clone the repository.
  2. Run node build.js.
  3. Use build-chrome/ or build-firefox/.

Tagged releases also publish .crx and .xpi artifacts on GitHub Releases.

2. Chrome / Edge / Brave

  1. Open chrome://extensions/.
  2. Enable Developer mode.
  3. Click Load unpacked and select build-chrome.

3. Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on….
  3. Select manifest.json inside build-firefox.

Temporary add-ons in Firefox unload when the browser restarts. Use a signed .xpi from Releases for persistence, or reload after restart while developing.

Usage

Overlay — On pages with a video, use Launch WebPlayer to inject the control and gesture layer.

Standalone — When an HLS/DASH stream is detected, confirm the prompt to open a dedicated player tab with EQ, themes, subtitles, and quality controls.

Keyboard shortcuts

Touch gestures

GestureAction
Swipe ↕ left halfBrightness

Horizontal swipeSeek by distance (5–60s)
Double-tap L / RSeek ±10s
Double-tap centerReset brightness, or toggle fullscreen
Long pressTemporary 2× speed

In Overlay mode, vertical brightness/volume swipes require fullscreen so they do not fight page scrolling. Standalone mode supports them anytime.
