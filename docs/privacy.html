Privacy

WebPlayer is open source and ad-free. This page explains what the extension accesses and what it does not do.

Last updated: September 18, 2026

Summary Data we handle Network Permissions What we don’t do Contact

Summary

WebPlayer runs locally in your browser. Preferences and playback progress stay in browser storage. The extension does not run its own analytics backend or sell personal data.

Data we handle

  • Player preferences — theme, equalizer curve, enhancer settings (stored via chrome.storage / Firefox storage; EQ may use sync storage when available).
  • Playback progress — resume positions keyed by media URL, with automatic cleanup of stale entries.
  • Pending stream metadata — short-lived URLs needed to reopen an intercepted HLS/DASH stream after a service-worker restart.

This information stays on your device (and, for sync-eligible keys, your browser sync account). We do not operate a WebPlayer account system.

Network requests

  • Media streams — the player fetches the video/audio URLs you open or that are detected on the page (including HLS/DASH manifests and segments).
  • SponsorBlock — when a YouTube video ID can be inferred, the extension may request skip segments from the public SponsorBlock API (sponsor.ajay.app).
  • CORS / header rules — Declarative Net Request session rules may adjust request/response headers so streams can play from the extension player page. Rules are scoped to the player tab and cleaned up when the tab closes.

Permissions (why they exist)

  • storage — save preferences and resume positions.
  • tabs / scripting — open the player and inject the overlay UI.
  • webRequest — detect .m3u8 / .mpd stream URLs.
  • declarativeNetRequest — enable playback that would otherwise fail due to CORS or referrer checks.
  • alarms — keep background cleanup tasks reliable under Manifest V3.
  • <all_urls> host access — overlay and stream detection work on sites where you watch video.

What we don’t do

  • No advertising network, no tracking pixels, no sold user profiles.
  • No remote code updates outside normal extension store / GitHub releases.
  • This marketing site may load Google Fonts when you visit these pages; that is separate from the extension runtime.

Contact

Questions or privacy concerns: open an issue on GitHub Issues or contact the maintainer via the repository.

Source of truth for behavior is the public codebase at github.com/sbhushan01/WebPlayer.
